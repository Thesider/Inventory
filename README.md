# InventoryApp

## Overview
InventoryApp is a cross-platform inventory management application built with .NET MAUI. It is designed to help users efficiently track and manage inventory items across multiple platforms, including Windows, macOS, Android, and iOS.

## Features
- Cross-platform compatibility using .NET MAUI
- Organized inventory management system
- Intuitive user interface with responsive design
- Data persistence for inventory tracking
- Utility functions for data processing

## Technologies Used
- **.NET MAUI**: Multi-platform UI framework for building native applications.
- **C#**: Core programming language for backend logic.
- **HTML, CSS**: Frontend structure and styling.

## Project Structure
- **Components/** – UI components for the application.
- **Data/** – Handles data storage and retrieval.
- **Model/** – Defines the data models used in the application.
- **Platforms/** – Platform-specific configurations for different operating systems.
- **Properties/** – Configuration files for the application.
- **Resources/** – Contains assets such as images and styles.
- **Utility/** – Helper functions for application logic.
- **View/** – User interface elements and pages.
- **ViewModel/** – Implements MVVM pattern for UI logic.
- **wwwroot/** – Static web assets.

## Installation & Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/Thesider/InventoryApp.git
   ```
2. Open the project in Visual Studio.
3. Install the required dependencies via NuGet.
4. Select the target platform and run the application.
